# ViowPink Landing Page

A modern, responsive landing page built with **React**, **Tailwind CSS**, **Zustand**, and **shadcn/ui**.  
It features a magic header, animated hero section, features grid, dynamic products section with state management, and a contact form — all styled with a vibrant violet-to-pink gradient theme.

## ✨ Features

- 🎨 **Violet → Pink Gradient Theme** for a fresh, modern aesthetic.
- 🚀 **Hero Section** with animated headings and call-to-action.
- 📦 **Dynamic Products Section** with Zustand state management.
- ⚡ **Add/Remove Products** directly from the UI.
- 📱 Fully **Responsive Design** for mobile, tablet, and desktop.
- 📬 **Contact Form** with quick links (Email, WhatsApp, Twitter).
- ✨ Smooth hover effects and transitions using Tailwind CSS.

## 🛠 Tech Stack

- **React** – UI library.
- **Tailwind CSS** – Utility-first CSS framework.
- **shadcn/ui** – Prebuilt, customizable UI components.
- **Zustand** – Lightweight state management.
- **Vite** – Fast development build tool.
